# NSL-KDD Dataset

Ce dossier contient les expériences réalisées sur le jeu de données NSL-KDD dans le cadre du mémoire :

**"Analyse comparative des algorithmes de Machine Learning appliqués à la détection d'intrusion."**

## Contenu

- notebooks : notebook Google Colab (.ipynb)
- scripts : code Python (.py)
- models : modèles entraînés (.pkl)
- figures : graphiques et matrices de confusion
- results : résultats des expériences (CSV, Excel)

Algorithmes évalués :

- Decision Tree
- Random Forest
- XGBoost
- K-Means
- Isolation Forest
